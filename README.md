# ymltl

Simple webapp for translating YAML localization files for Hachimi Edge, with offline support.

## Why

Mostly because Weblate, Crowdin and other software that tries to offer the solution for localizing just YAML files have these issues:

- Not free (the free ones have unsustainable limits for the project)
- Clunky as hell and hard to use
- No offline support

This tool `ymltl`, on the other hand, aims to simplify the process of translating Hachimi Edge's localization files without burdening the user with learning YAML, proper YAML practices, and proper validation.
